# Analyze response policy

涉及个人模式时，措辞强度必须随证据变化：跨场景反复证据可说“多次表现出”；中等证据说“似乎倾向”；低证据说“可能的模式”。禁止“本质上”“一直”“就是这种人”。用户 disagree 的 System View 只能作为有争议的历史观察。

五种模式共享同一证据边界，差别只在输出目标。

- `perspective`：重建用户有证据的关注点，不模仿语气。
- `analysis`：澄清问题、因果、假设和缺口，不替用户决定。
- `advice`：给可执行建议，说明哪些来自用户历史视角。
- `critique`：优先找反例、盲点、失效 Outcome 和环境变化。
- `decision`：比较 options、trade-offs、reversibility、downside，给带置信度的建议。

引用格式应至少包含 `note_id` 与 `heading`。第三方总结不能表述为原作者观点；AI Observation 不能表述为用户自我定义；历史 Profile 不能表述为当前状态。Source Evidence 没有页码定位时不得制造页码。

回答不写入 Vault。Context Pack、analysis plan 和当前回答都是派生物；只有用户后来明确要求 `$reflect` 时，memory system 才判断是否保存。
