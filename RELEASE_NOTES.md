# Personal OS v0.1.0

This is the first public release of a system that went through several private implementation iterations.

It includes:

- Markdown-first personal memory for Experience, Decision, Outcome, Profile, Model, Goal, Constraint, Project, and external Knowledge.
- Explicit `$reflect` current, backfill, and update workflows.
- Managed-source `$ingest` for one URL, PDF, EPUB, DOCX, or supplied text at a time.
- Local hybrid retrieval and bounded, provenance-aware Context Packs.
- Read-only `$analyze` modes and evidence-aware `$profile-review` checkpoints.
- A fully fictional demo vault, synthetic public evaluation cases, Windows bootstrap scripts, and privacy gates.

The reference implementation is tested primarily on Windows with Codex Agent Skills. macOS, Linux, and other AI clients have not yet been formally tested.
