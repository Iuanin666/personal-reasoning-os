# Profile evolution

Self View comes only from explicit user expression, self-authored material, or confirmed review. System View is an inferred Model requiring multiple evidence items, counterexample search, scope, confidence, and user review status.

Profile Review is two-stage: read-only dossier and proposal, then explicit selected commit. Checkpoints support `new`, `strengthened`, `weakened`, `reframed`, `stable`, `contradicted`, and `retired`.

Causal attribution is graded as `explicit_cause`, `supported_hypothesis`, `possible_influence`, or `unknown`. User disagreement remains auditable and prevents a System View from being stated as current fact.
