# Privacy model

The public repository contains no real user vault. A local deployment may hold highly sensitive Markdown, source files, logs, and derived indexes. Back up the Markdown and managed sources; treat indexes and caches as sensitive even though they are disposable.

The application performs no automatic upload. When an AI client reads evidence, that content is handled under that client's environment and policies. Users control when reflect, ingest, context, analyze, and profile review run.

Before publishing a fork, run the denylist and content scans and inspect Git history, not only the working tree.
