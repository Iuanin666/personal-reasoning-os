# Open-source design

The public edition starts from a sanitized tree with fresh Git history. It excludes private Markdown, source evidence, indexes, caches, internal evaluations, operation logs, backups, conflict artifacts, and machine-specific runtime files.

The public version is `0.1.0`; internal version numbers are implementation history, not a fabricated public release series. Public evaluations use synthetic data and expose methods rather than private answers.

Generic parsing is delegated to Defuddle and Docling. Personal OS owns personal-memory semantics, source identities, evidence rules, context selection, and profile evolution.
