# Memory model

- **Profile**: current, stable, explicitly supported Self View.
- **Experience**: events with `event_date`, `recorded_at`, and provenance.
- **Decision / Outcome**: choice, assumptions, trade-offs, and later observed result.
- **Goal / Constraint / Principle**: current authoritative context.
- **Project**: bounded work context.
- **Model / AI Observation**: evidence-based System View, never disguised as user fact.
- **Profile History**: checkpoints, prior states, disagreements, and evolution.
- **Knowledge**: external or self-authored material with source identity.

Backfill separates event time, material identity, and import operation. Updates retain earlier states. Similarity alone never proves two events are identical.
