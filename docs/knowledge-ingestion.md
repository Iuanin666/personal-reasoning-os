# Knowledge ingestion

Defuddle extracts one web article. Docling extracts one PDF, EPUB, or DOCX. Personal OS adds source identity, hashes, provenance, Knowledge semantics, conflict planning, CAS publication, and indexing.

Original extraction, third-party summary, AI summary, and personal reflection are distinct. Full extraction belongs in `04_Knowledge/_Sources/<source_id>/`; the ordinary Knowledge note keeps metadata, source reference, outline, and explicitly requested derived content.

Source changes produce update or conflict. They never silently overwrite personal reflection or upgrade a third-party summary into an author's claim.
