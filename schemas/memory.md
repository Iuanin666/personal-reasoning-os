# Memory schema

All notes use UTF-8 Markdown with YAML frontmatter. Stable fields include `type`, `id`, `title`, `event_date`, `event_date_precision`, `recorded_at`, `updated_at`, `provenance`, and explicit relation lists.

Profile uses current explicit statements. Experience records events. Decision records options, reasons, assumptions, and appendable Outcome. Model records evidence-based observations and counterevidence. Profile History records checkpoints and earlier states.
